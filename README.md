## 📝 Description
This plugin adds placeable Brazen Bulls to Counter-Strike 1.6, allowing players to burn and execute themselves or other players inside medieval torture devices.
- Place and configure Brazen Bulls around the map
- Capture players inside the Brazen Bull with animated opening and closing sequences
- Burn trapped players with configurable fire effects and damage
- Execute trapped players after a configurable holding duration
- Customize execution messages and forced execution messages
- Configure affected teams and usage restrictions by team
- Customize usage cooldowns and animation framerate
- Play configurable opening, closing, fire, bell and scream sounds
- Display customizable fire effects with adjustable color, scale and transparency
- Display customizable HUD effects during executions
- Configure whether sounds and messages are displayed on death
- Configure whether the victims camera follows the execution
- Save and load Brazen Bull placements per map
- Configure default behavior and create custom Brazen Bull presets

## ⚙️ Configuration
```ini
# To add a new Brazen Bull, follow the example below:
# [Brazen Bull Name]
# BULL_TEAM       = 0 - None, 1 - Terrorist, 2 - Counter-Terrorist, 3 - Both
# BULL_COOLDOWN   = Minimum and maximum cooldown duration (MIN MAX)
#
# Define a section name to make a Brazen Bull available in the menu.
# Models and sounds cannot be changed dynamically during gameplay.
```
